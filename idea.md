This is a voting/poll platform for selecting restaurant locations for team lunch. It should be open to the public but accessed via a referral link. (link parameter at the end of the referral link), which will take users directly to a session that I can set in the backend.

It should display a map with a selected center point, usually set by the admin (typically the office). Voters can see how close each restaurant is to the center point in terms of driving distance. We will use Google Maps data for reviews, images, and other restaurant information. 

Obviously, a voter can cast a vote, and we as admins can define how many in total. this is to control the total number of votes.

We need a feature to store restaurants that have already won the vote (admin enter + auto capture from previous votes), so we don’t repeat them in the future
